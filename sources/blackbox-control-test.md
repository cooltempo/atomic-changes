# Black Box Digital Control (Test) changelog

Test builds for Team Atomic only. Versions stay below 1.0 until launch.

## 0.0.1 · 6 Nov 2026
- **The first test build.** Control (Test) for the Black Box HG-Q, as AU, VST3 and AAX on Mac. It is listed under Black Box Digital in the DAW.
- **Every HG-Q setting is a plug-in parameter.** Settings automate and are saved with the session. Audio passes through unchanged.
- **No connect button.** Every instance finds the unit on its own and shows the same settings. A new instance takes the unit's current settings; a session or preset is sent to the unit once it connects.
- **Link.** With Link on, a change to one channel is copied to the other.
